# Project screenshots

Same rules as `../products/README.md`. Filenames must match the `image` field
in `client/src/lib/data.ts` → `projectsData`.

| File | Project | Source |
| --- | --- | --- |
| `universal-brew.avif` | Universal Brew | https://universalbrew.shop |
| `hackovate.avif` | Hackovate LJ | https://hackovate.live |

`Smart Attendance System` and `COVID-19 Data Analysis` have no `image` set —
they have no live site, so they render the generated placeholder. If you have
photos or plots for them, add the file here and set `image` in `data.ts`.

- **16:10**, target **1280×800**, AVIF preferred.
- A missing file is not an error — the placeholder covers it.
